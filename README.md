# Система отзывов о городских местах

## Назначение

Сервис для публикации и просмотра отзывов о городских местах: достопримечательностях, ресторанах, кафе и других точках, интересных туристам и местным жителям. Пользователи могут добавлять места, оставлять отзывы с оценкой и комментарием.

## Целевая аудитория

- Туристы
- Местные жители

## Предметная область

Городские места и отзывы посетителей о них. Место описывается названием, адресом и кратким описанием; отзыв содержит оценку и текстовый комментарий.

## Основные сущности

- Пользователь
- Место
- Отзыв

## Основные функции

- Создание места
- Удаление места
- Создание отзыва
- Удаление отзыва

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django
- подключение базы данных
- реализация пользователей и аутентификации
- добавление категорий и тегов для мест
- добавление геолокации
- автомодерация отзывов
- разработка REST API
- контейнеризация приложения, используя Docker
- настройка CI/CD
