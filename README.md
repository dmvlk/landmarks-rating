# Система отзывов о городских местах

## Назначение

Сервис для публикации и просмотра отзывов о городских местах: достопримечательностях, ресторанах, кафе и других точках, интересных туристам и местным жителям. Пользователи могут добавлять места, оставлять отзывы с оценкой и комментарием.

## Целевая аудитория

- Туристы
- Местные жители

## Предметная область

Городские места и отзывы посетителей о них. Место описывается названием, адресом и кратким описанием; отзыв содержит оценку и текстовый комментарий.

## Основные сущности

- Пользователь
- Место
- Отзыв

## Основные функции

- просмотр списка мест;
- поиск мест по названию;
- добавление новых мест;
- удаление мест (с каскадным удалением связанных отзывов);
- добавление отзывов с оценкой (1-5) и комментарием;
- просмотр списка отзывов;
- подсчёт средней оценки для выбранного места;
- удаление отзывов;
- сохранение данных между запусками в JSON-файлах.

## Структура проекта

- `main.py` - точка входа
- `app/places.py` - функции для работы с местами
- `app/reviews.py` - функции для работы с отзывами
- `app/storage.py` - сохранение и загрузка данных
- `app/utils.py` - вспомогательные функции безопасного ввода
- `data/` - JSON-файлы данных
- `tests/` - тесты
